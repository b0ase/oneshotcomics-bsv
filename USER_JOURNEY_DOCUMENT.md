# One-Shot Comics - Correct User Journey Document

## Overview

One-Shot Comics is an **AI-powered comic creation platform** that allows users to create, mint, and trade NFT comics through a **progressive workflow**. The ultimate goal is to enable users to mint a complete comic with **one button press**, but the platform breaks this down into multiple stages to allow for editing and refinement.

## Core Concept: "One Shot" Minting

The platform's name "One-Shot Comics" refers to the **ultimate goal**: minting a complete comic in "one shot" (one button press). However, during development, this is broken down into multiple stages to allow users to:

1. **Edit AI-generated content** at each stage
2. **Refine and customize** their comics
3. **Learn the workflow** before the final one-shot feature
4. **Ensure quality** through human oversight

## User Journey: Left to Right Navigation

The user travels **left to right** across the navbar, with each section building upon the previous one:

### **1. Series (Foundation)**
**Purpose:** Establish the comic universe and foundation
- **Series Generator:** AI generates series concepts with characters and storylines
- **Series Config:** Configure series parameters and settings
- **Series Variables:** Define world-building elements and series-specific terminology

### **2. Characters (Cast)**
**Purpose:** Create and manage characters for the series
- **Character Generator:** AI generates heroes and villains with detailed profiles
- **Character Config:** Configure character generation parameters
- **Character Variables:** Define character traits, powers, and appearance options
- **Character Library:** Browse and manage all created characters

### **3. Stories (Narrative)**
**Purpose:** Create compelling storylines and plots
- **Story Generator:** AI generates stories using selected characters and variables
- **Story Config:** Configure story generation parameters
- **Story Variables:** Define story elements like genre, setting, tone, conflict, theme

### **4. Scripts (Dialogue & Action)**
**Purpose:** Convert stories into detailed comic scripts
- **Script Generator:** AI converts stories into panel-by-panel scripts
- **Saved Scripts:** Browse and manage all created scripts

### **5. Artwork (Visual)**
**Purpose:** Create visual assets for the comic
- **Images:** AI generates artwork based on scripts and character designs
- **Frame Generator:** Create comic panel frames and layouts

### **6. Comics (Assembly)**
**Purpose:** View and manage completed comics

### **7. Mint (NFT Creation)**
**Purpose:** Convert comics into NFT assets
- Select comics for minting
- Set minting parameters (supply, price, rarity)
- Execute minting transactions

### **8. Market (Trading)**
**Purpose:** Buy, sell, and trade NFT comics
- Browse available comics
- List comics for sale
- Trade with other users

### **9. Wallet (Management)**
**Purpose:** Manage cryptocurrency wallet and transactions

### **10. Token ($1SHOT)**
**Purpose:** Platform token for rewards and governance
- Earn $1SHOT tokens by creating comics
- Stake tokens for dividends
- Participate in platform governance

## AI-Powered Workflow

### **Current Stage (Multi-Step Process)**
1. **Series Creation:** AI generates series concept → User edits → Save
2. **Character Creation:** AI generates characters → User selects/edits → Save
3. **Story Creation:** AI generates story → User edits → Save
4. **Script Creation:** AI converts story to script → User edits → Save
5. **Artwork Creation:** AI generates images → User selects/edits → Save
6. **Comic Assembly:** User combines all elements → Review
7. **Minting:** User mints comic as NFT → List on marketplace

### **Future Stage (One-Shot Process)**
1. **One Button Press:** AI generates complete comic from scratch
2. **Automatic Assembly:** All elements combined automatically
3. **Quality Check:** AI validates comic quality
4. **Direct Minting:** Comic automatically minted as NFT
