## Usage

Each character directory contains:
- **image-prompt.txt** - Character information, detailed image generation prompt, key visual elements, and art style specifications
- **pose-1/** - Directory for first pose variation images
- **pose-2/** - Directory for second pose variation images  
- **pose-3/** - Directory for third pose variation images

These prompts are designed for:
- AI image generation tools (DALL-E, Midjourney, Stable Diffusion)
- Traditional artists
- Digital artists
- Character reference sheets

## Pose Directory Usage

The pose directories (pose-1, pose-2, pose-3) are designed to organize different character poses and variations:

- **pose-1/** - Primary/standard pose for the character
- **pose-2/** - Secondary/action pose for the character
- **pose-3/** - Tertiary/dramatic pose for the character

Each pose directory can contain:
- Generated character images
- Reference images
- Pose-specific variations
- Different angles or perspectives

## File Format

Each `image-prompt.txt` file follows this structure:
```
Character: [Character Name] - [Alias]
Series: [Series Name]
Type: [Hero/Villain/Anti-Hero]
Alignment: [Hero/Villain/Anti-Hero]

IMAGE PROMPT:
[Detailed description for image generation]

KEY VISUAL ELEMENTS:
- [Element 1]
- [Element 2]
- [Element 3]
...

ART STYLE: [Style description]

CRITICAL CONSISTENCY NOTES:
- [Specific requirements for consistency]
```

## Notes

- All prompts are optimized for consistent character representation
- Each prompt includes specific art style guidance
- Visual elements are prioritized for character recognition
- Backgrounds and effects are tailored to each character's theme
- Prompts can be modified or expanded based on specific needs
- Pose directories allow for organized storage of multiple character variations
